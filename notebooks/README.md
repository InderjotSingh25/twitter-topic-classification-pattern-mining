# Notebooks

Put your Jupyter notebook(s) here, for example:

- `twitter_topic_classification_and_pattern_mining.ipynb`

The notebook should contain the full pipeline: cleaning, pre-processing, the 80/20 split
(`random_state=42`), the four classifiers, cross-validation, Apriori / FP-Growth and
export of the CSV tables in `data/processed/`.
