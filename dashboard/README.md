# Power BI dashboard

Put your Power BI file here:

- `twitter_dashboard.pbix`

Open it in Power BI Desktop. If the data sources show an error, go to
**Home > Transform data > Data source settings** and point each CSV to
the `data/processed/` folder of this repository.

Also add the exported dashboard PDF (Pattern mining, Algorithms, Performance pages):

- `twitter_dashboard.pdf`
